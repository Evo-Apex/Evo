## 显示规则

- 段位和 RP 按游戏里的方式显示，如"钻石 I · 48 排位点数"：不显示分母、进度条和"距下一段还差"（每段要多少分不一样）
- 读不到的数据显示"—"
- 不让页面跳（2026-11-02，合并 PR #3 时查的；用户要保留动效）：动效（页面切换、展开一局、走势图、数字滚动）只改位置偏移和透明度，不会挤开别的内容。会让内容挪动的是这三种：①字体：每打开一页都先问一遍变了没有，问的时候数字和英文先用系统字体画，回来换成 Chakra Petch，宽窄不同（`panel_app.cache_fonts` 让窗口直接用缓存；以后换字体要换文件名）；②滚动条有时有时无，内容跟着变窄（`.in-app body` 的 `scrollbar-gutter: stable` 一直留着它的位置）；③后来才填进去的内容：战绩页的截图（`<img>` 上写截图的宽高，下载前就留好位置）、总览页的当前地图（每格 `min-height` = 取到数据以后的高度，"正在获取…"时也一样高）、设置页截图那两行的数字（"正在统计…"一行字，常见的"没有可以删的截图"换上去也是一行）。以后加晚到的内容，也要事先留好位置
- 不要横向滚动条（2026-11-04）：窗口里出现横向滚动条，就是有东西比窗口宽。量法：Edge 无界面模式打开每一页（带 `EvoApp/` 的 User-Agent），比 `document.body.scrollWidth` 和 `clientWidth`，列出右边超出窗口的元素。11-04 那次是总览页六维图下面给读屏软件的数字表（`.sr-only`）被 `table.stats-table` 的 `width: 100%` 撑回整行宽；现在 `.sr-only` 的几项都加了 `!important`。不靠给 body 加 `overflow-x: hidden` 遮住（PR #3 那样遮过，11-02 清理时去掉了才又露出来）：遮住会把真的放不下的内容裁掉
- 传奇名字前有小头像（战绩页自己和队友、总览页最近对局和传奇表现；2026-10-20 用户决定）：18 像素，单色、颜色跟随文字（原图是黑色的，深色主题下看不见），名字就在旁边，读屏软件跳过它；没有图标时（没认出、以后的新传奇）留出同样宽的空位，名字上下对齐。写法在 `panel/templates/_legend.html`，样式 `.legend-icon`
- 传奇头像的来源和许可：原图（Apex Legends Wiki 上的 SVG）放 `assets/legends/`，每个文件的许可不一样，写在那里的 `LICENSE.txt`（不适用 AGPL-3.0；新加的图标要先写进去）。`python tools/legend_icons.py` 按 `config/legends.json` 的英文名对上编号，去掉编辑信息、四周空白裁成一样多，生成 `panel/static/legends/<编号>.svg`，并把许可文件复制过去（随安装包发）。出了新传奇：放原图、写许可、运行一次

- 截短的名字（"要公面前刀大"和"要公面前刀大关"）不自动归，照旧弹窗问（2026-11-19 用户定的）：分不出是少读了一个字，还是玩家真有 `EvilScholar` 和 `EvilScholar2` 两个号，并错了两个号的战绩就混在一起
- 设置页每个已确认的账号可改展示名（待确认的不行：回答以后可能并进别的账号，编号空出来会留给以后的新账号）；展示名用于账号切换、设置页和分享图，清空后恢复最近一次识别名。每局的 `player_name`、识别名列表、账号匹配和筛选始终使用 OCR 原文，不会被展示名改掉
- 设置页"账号"一栏每个账号一块（2026-11-19 改的：玩家反馈原来每个名字一行、并过的名字也占一行，越堆越多）：标题是展示名（没改过就是最近一局的名字），下面写局数、最近一局，几个名字或改过展示名时再写"游戏里的名字：…"。改展示名、每个名字属于哪个账号（并到别的账号、拆成单独一个）收在"改展示名、合并或拆开…"里（链接样式，同"更改数据位置…"），展开的内容左边一条竖线。待确认的账号（还没回答弹窗）展开着，只有一行"属于哪个账号"，几种写法一起处理，同弹窗
- 删除一个账号（2026-11-05 用户要的，比如不想要的小号）：设置页"账号"一栏最后一行，2 个以上账号时才有（只有一个时用"清空所有战绩"）。下拉框默认不选，选了"删除"才能点，确认框写明账号名和局数。删掉这个账号所有名字的局（连同队友、各来源读数、武器）、回大厅读到的段位、历史赛季数据，这些局的截图也删（用户决定，同战绩页删一局；开着"保留全部截图"时不删）；删前备份数据库（`evo.db.bak-account-时间`）。名字从对照表去掉：删掉的号以后照样记录，再打时当成新名字弹窗问（用户决定，不做"不记录"名单）。绑定了小程序的，删掉的局下次同步时云端也删（`storage.delete_account`、`panel_app.delete_account`）
- 记录时同一次记录里读到的名字：和之前的很像（≥ 0.8）当作识别误差；一个是另一个的开头、短的至少 8 个字时当作被截短了（总结页卡片上名字太长时游戏会截短，2026-11-04），记完整的那个，这次记录里已经存下的局也改过来（`post_match.on_player_name`）

## 分享战绩（2026-10-21）

- 用户决定：三种卡片都做；队友只显示传奇和这一局的数据，不写名字和 ID；自己的游戏名默认显示，分享前能勾掉。不做"分享链接"（要上传到服务器，违反原则 2）
- 入口：战绩页点开一局，"详情与修改"左边的"分享这局"（待确认的局没有：数据还没确认）；总览页段位卡片右上角"分享"（"今日战绩"和"近 30 局概况 / 全部概况"，范围跟着总览页的按钮，总览页选的是本赛季 / 上赛季时用近 30 局（2026-11-03 用户没要求分享按赛季）；今天没打时"今日战绩"不能选；"全部账号"时没有）
- 对话框（`panel/templates/_share.html`）：预览、"在图上显示我的游戏名"（没认出玩家名时不显示这一项）、有待确认的局时提醒"确认后图上的数字更准"、"复制图片"（写进剪贴板，到微信、QQ 里 Ctrl+V）、"保存图片…"（Evo 窗口里弹 Windows 的"另存为"，默认"图片"文件夹，`app_window.save_image`，只收 PNG；用浏览器打开的面板直接下载）
- 卡片（`panel/templates/share/*.svg`，数据在 `panel_app.py` 的"分享战绩"）：SVG 里放一段网页排版（foreignObject），字体、传奇头像、段位图标、Evo 图标都嵌成 data: 网址；页面把它画成 2 倍大小的 PNG（单局、今日 1440×810，概况 1440×1080）。固定用黑夜主题的颜色，不跟随面板主题；右下角"EVO evotracker.cn"
  - 坑：SVG 要用 data: 网址载入再画到 canvas 上；用 blob: 网址载入的话（里面有 foreignObject），浏览器不让导出
  - 坑：写剪贴板要窗口在前台（自动化测试时窗口在后台会报"Document is not focused"）；ClipboardItem 直接交一个还没完成的 Promise，免得生成慢了超过"刚点过按钮"的时限
- 单局：名次（冠军写"冠军"，按名次上色，和徽章一样）、传奇、模式 · 地图 · 日期时间、击杀 / 助攻 / 击倒 / 伤害 / 生存、RP（只有排位局）、打完这局的段位、两名队友的传奇和数据
